# Bitcoin Sin Ruido ⚡

Divulgación técnica del protocolo Bitcoin en español.
Sin precio. Sin hype. Solo protocolo.

## Sobre el proyecto

Bitcoin Sin Ruido es la referencia hispanohablante 
de contenido técnico riguroso sobre Bitcoin:
protocolo, capas, mejoras y debates.

## Temas que cubrimos

- Lightning Network
- Taproot y firmas Schnorr
- BitVM y ZK-rollups
- Covenants (OP_CAT, CTV)
- Resistencia cuántica (BIP-360)
- Gobernanza y BIPs

## Stack técnico

- Next.js 14 + TypeScript
- Tailwind CSS
- MDX para contenido
- Cloudflare Pages (hosting)
